# 落雪音乐歌单一键下载器

自动读取落雪音乐桌面版（lx-music-desktop）本地数据库中的歌单，批量下载所有歌曲到本地磁盘。

## 功能特性

- **一键下载**：自动识别本机落雪音乐数据库，列出所有歌单（默认列表、我的收藏、自定义歌单）
- **多平台支持**：酷我(kw)、网易云(wy)、腾讯(tx)、酷狗(kg)、咪咕(mg)
- **多级兜底**：
  1. 原平台精确 ID 获取播放链接
  2. 多音质候选（320k → 128k 自动降级）
  3. 同名歌曲其他平台替代源
  4. 按「歌手+歌名」全网搜索兜底
- **链接有效性校验**：下载前自动 HEAD 验证，跳过失效链接
- **并发下载**：多线程下载，支持断点跳过（已存在文件自动跳过）
- **失败清单**：失败的歌曲写入 `failed.txt`，可重试

## 使用方法

### 命令行运行（交互式选择歌单）

```bash
python lx_music_downloader.py
```

### 常用命令

```bash
# 列出所有歌单
python lx_music_downloader.py --list

# 下载指定歌单（我的收藏）
python lx_music_downloader.py --playlist love

# 下载指定歌单到指定目录，指定音质和并发数
python lx_music_downloader.py --playlist love --quality flac --dir D:/Music --workers 8

# 仅下载前 N 首（测试用）
python lx_music_downloader.py --playlist love --max 10
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--db` | 落雪音乐数据库路径 | 自动检测（%APPDATA%/lx-music-desktop/LxDatas/lx.data.db） |
| `--list` | 列出歌单 | - |
| `--playlist / -p` | 歌单 ID（default/love/自定义） | 交互选择 |
| `--quality / -q` | 音质：128k / 320k / flac / flac24bit | 320k |
| `--dir / -d` | 下载目录 | ./downloads |
| `--workers / -w` | 并发下载数 | 3 |
| `--node` | Node.js 路径 | 自动检测 |
| `--api` | 音源脚本路径 | - |
| `--api-dir` | 按顺序加载目录内全部 JS/JSON 音源 | `%APPDATA%\lx-downloader-sources` |
| `--exclude` | 排除歌曲名或“歌手 - 歌名”，逗号分隔 | - |
| `--max` | 最多下载数量 | 全部 |

## 工作原理

```
┌─────────────────┐     ┌──────────────────┐     ┌──────────────┐
│ 落雪音乐数据库   │     │ Node 音源桥接服务  │     │  用户音源     │
│ lx.data.db     │────▶│ lx_url_server.js │────▶│ %APPDATA%    │
│ (歌单+歌曲信息)  │     │ (模拟 lx 环境)    │     │ lx-downloader│
└─────────────────┘     └──────────────────┘     │ -sources/    │
        │                         │              └──────────────┘
        │  读取歌单、解析歌曲ID     │  获取播放链接(多候选)   │ 调用各平台API
        ▼                         ▼                        ▼
┌─────────────────────────────────────────────────────────────┐
│  Python 主程序 lx_music_downloader.py                       │
│  1. 读取歌单 → 2. 获取链接(自动降级/替代源/按名搜索)          │
│  3. HEAD 校验 → 4. 并发下载 → 5. 输出失败清单                 │
└─────────────────────────────────────────────────────────────┘
```

## 文件说明

| 文件 | 说明 |
|------|------|
| `lx_music_downloader.py` | Python 命令行主程序（唯一入口） |
| `lx_url_server.js` | Node 音源桥接服务（加载用户音源、取播放链接、按名搜索兜底） |
| `sources/` | 音源占位目录（**不捆绑任何第三方音源**，见下方「音源管理」） |
| `scan_sources.py` | 音源健康检查工具（对歌单抽样，逐个音源实测可用性） |
| `analyze_quality.py` | 下载文件质量分析工具（按内容探测码率/格式） |
| `_probe_sources_v2.py` | 音源探针（逐源跑 searchByName 全流程） |

### 音源管理（用户自备）

本工具**不内置、不分发任何第三方音源脚本**。音源由使用者自行导入，统一保存在：

```text
%APPDATA%\lx-downloader-sources\
```

- GUI「音源」页可导入/删除音源文件（.js / .json / user_api.json）
- 也可以直接把音源 JS 或落雪桌面版导出的 `user_api.json` 放进该目录
- 引擎默认从该目录加载全部音源；目录为空时提示「请先导入音源」并中止
- 某个音源连续拿不到有效链接会自动冷却（默认 3 分钟），避免死源拖慢下载
- 命令行可用 `--api <文件>` 指定单个音源，或用 `--api-dir <目录>` 指定其它目录
- 健康检查：`python scan_sources.py` / `python _probe_sources_v2.py`（同样读取用户音源目录）

## EXE 打包

已提供控制台模式单文件 EXE：

```text
dist/LXMusicDownloader.exe
```

双击 EXE 会打开命令行主菜单：

```text
1. 下载歌曲
2. 设置
3. 重置设置
0. 退出
```

“设置”可以持久化修改数据库路径、下载目录、默认音质、失败后自动降低音质、并发数、Node.js 路径、单个音源文件和音源目录。默认音质在设置里用 `1-5` 选择：`1=128k`、`2=192k`、`3=320k`、`4=flac`、`5=flac24bit`。开启“下载失败自动降低音质”后，会从当前音质向下逐级尝试，最低只降到 `192k`，例如 `flac24bit → flac → 320k → 192k`，不会降到 `128k`；只有下载和严格时长校验都成功才会结束尝试。默认该选项关闭。默认下载目录是程序目录下的 `downloads` 文件夹。EXE 已内置 Node.js，一般不需要用户安装 Node.js。配置保存到 `%APPDATA%/lx-downloader-config.json`。也可以在命令提示符中直接传入 `--fallback-quality` 覆盖设置。

## 依赖

- Python 3.8+（源码运行时，仅标准库）
- Node.js 18+（需支持全局 fetch；EXE 运行时仍需可用 Node.js）

## 常见问题

**Q: 提示找不到数据库？**
确保落雪音乐桌面版已安装并运行过（首次运行会创建数据库）。

**Q: 部分歌曲下载失败？**
音源接口时效性强，失败歌曲已记录到 `failed.txt`。稍后重新运行本程序会自动跳过已下载的歌曲，只处理剩余的。

**Q: 音质与预期不符？**
部分平台/歌曲可能不支持所请求的音质，会自动降级到可用音质。

**Q: 音源失效怎么办？**
将最新的音源 JS 放到 `sources/` 目录，或用 `--api` 指定音源文件路径。
